₿ Connect Crypto Exchange

Follow these steps to create a read-only API key and connect your exchange account.

📋 Universal Steps

1
Log in to your exchange → click your Account/Profile icon (usually top-right corner).
2
Find API Management — may be under Security Settings or Developer Tools.
3
Click Create API or Generate New Key.
4
Label it Tragene Journal Sync for easy identification.
5
Enable Read/Read-Only permission.
6
Disable Trade permission (unless required) and ALWAYS disable Withdraw.
Never enable withdrawal permissions on any API key you share with a third-party tool.
7
Add IP restriction if offered (optional but recommended).
8
Complete 2FA/email verification to confirm creation.
9
Copy API Key + Secret immediately (secret shown once) and paste into Tragene's Connect Exchange form.

🔍 Exchange-Specific Guides

Binance
  • Profile Icon → API Management → Create API
  • Choose "System-generated" key type
  • Enable only "Enable Reading" permission
  • IP restriction: Optional (recommended)
  • No passphrase required
Bybit
  • Profile → API → Create New Key
  • Select "Read-Write" then uncheck all except "Read"
  • No passphrase required for API v5
  • IP whitelist: Recommended
KuCoin
  • Profile → API Management → Create API
  • Requires trading password to create keys
  • Enable only "General" permission (read-only)
  • Passphrase required — save it securely
OKX
  • Profile → API → Create API Key
  • Passphrase is mandatory
  • Enable only "Read" permission
  • IP whitelist: Recommended
Bitget
  • Profile → API Management → Create API
  • Passphrase required
  • Enable only "Read" permission
  • No IP restriction by default
Coinbase
  • Settings → API → New API Key
  • Requires Organization ID + Key + Secret
  • Enable only "Read" scope
  • Passphrase not required
MEXC
  • Profile → API Management → Create API
  • No passphrase required
  • Enable only "Read" permission
  • IP restriction: Optional

❓ FAQ — Crypto Exchange

Is it safe to share my API key with Tragene?
Yes. We only require read-only API keys. These keys cannot execute trades or withdraw funds. The exchange itself enforces these restrictions — we literally cannot use them for anything other than viewing your trade history.
I can't find the API Management menu
Different exchanges place this under different names. Try searching for "API" in your account settings search bar. Common locations: Profile → Security → API, or Profile → Developer Tools → API.
My sync is not working after connecting
Check that: 1) Your API key is still active, 2) Read permission is enabled, 3) Your IP hasn't changed (if IP restricted), 4) The key hasn't expired. Try disconnecting and reconnecting with a fresh key.
I accidentally leaked my API key — what now?
Immediately go to your exchange's API Management, delete the compromised key, and create a new one. Then update the credentials in Tragene. Since our keys are read-only, the damage is limited, but you should still act quickly.

📊 Connect MT4 / MT5

Use your Investor Password to connect MetaTrader safely — read-only access guaranteed.

📋 Universal Steps

1
Open your MT4/MT5 terminal or broker's client portal.
2
Locate your account number/login, server name, and investor password — found via Terminal → right-click account → Manage Accounts, or in your broker's welcome email.
3
If no investor password exists, generate one: right-click account in Terminal → Change Investor Password → set new (separate from main trading password).
4
Note the server name exactly as displayed (case-sensitive, e.g. ICMarketsSC-Live05).
5
In Tragene dashboard → Connect Account → MT4/MT5 → enter Account Login, Server Name, Investor Password.
6
Click Connect — access is read-only, view trade history only, cannot trade or withdraw.
Never share your MAIN trading password — only the read-only Investor Password is required.

❓ FAQ — MT4/MT5

What's the difference between Investor and Trading password?
The Trading (Master) Password allows full access — placing trades, modifying orders, withdrawing funds. The Investor Password is read-only — you can view account history and open positions but cannot execute any trades. Always use the Investor Password for third-party tools.
I can't find "Manage Accounts" option in Terminal
In MT4: Open Terminal (Ctrl+T) → right-click anywhere in the account section → "Login to Trade Account" or "Manage Accounts". In MT5: Navigator panel → right-click your account → "Change Investor Password" or check your broker's client portal.
My server name is not listed
The server name must be entered exactly as shown in your MT4/MT5 terminal. It's case-sensitive. Check your broker's welcome email or client portal if you can't find it in the terminal. If your broker uses a custom server, contact their support.
My trades are not syncing after connection
Check that: 1) The server name is exactly correct (case-sensitive), 2) The account number is correct, 3) The investor password hasn't been changed, 4) Your broker hasn't blocked API connections. Try disconnecting and reconnecting.
